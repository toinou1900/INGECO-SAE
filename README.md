# INGECO TERRITOIRES - Site Vitrine

![Aperçu du projet](./../INGECO-SAE/WEB-PAGE/INGECO/img/logo/Accueil.png) <!-- Remplacez ce lien par une capture d'écran de votre site -->

> **Projet SAE 05-06**  
> Site vitrine facilitant l'accès à des services de proximité dans les domaines de l'emploi, de l'insertion professionnelle, de la formation et de l'accompagnement.

## 📝 Présentation du Projet

INGECO TERRITOIRES accompagne les personnes dans leur parcours vers l'emploi, la formation et l'insertion, en lien avec les acteurs du territoire. 

Ce projet consiste en la création de leur site vitrine. Il a pour but de présenter la structure, ses actions locales, ses parcours de formation et les offres diffusées (emplois, stages, alternances). Le site sert également de passerelle vers des plateformes de services externes (notamment pour la gestion des inscriptions aux formations).

### Public cible
- Personnes en recherche d'emploi ou en insertion.
- Bénéficiaires de dispositifs d'accompagnement.
- Entreprises et professionnels.
- Structures locales et partenaires.
*(Une attention particulière est portée sur l'accessibilité et la simplicité d'utilisation pour les personnes peu à l'aise avec le numérique).*

## 🎯 Objectifs principaux

1. Présenter la structure, son équipe, ses actions, formations et offres.
2. Permettre un accès simple aux services externes.
3. Faciliter la prise de contact.
4. Rendre le site modifiable pour la cliente (mise à jour des contenus sans toucher au code HTML).
5. Proposer une interface responsive et évolutive.

## 🛠️ Technologies Utilisées

Ce projet est développé sans backend ni base de données complexe pour sa première version :
- **HTML5** : Structure sémantique.
- **CSS3** : Mise en page, design responsive et animations (Flexbox/Grid).
- **JavaScript (Vanilla)** : Dynamisation du site et chargement asynchrone des données (offres, formations) à partir d'un fichier modifiable par la cliente.

## 📂 Architecture du Site

Le site est composé des sections/pages suivantes :
*   **Accueil** : Présentation rapide et accès aux rubriques clés.
*   **Présentation** : Mission, valeurs, fondatrice et équipe.
*   **Actions** : Ateliers, événements et projets territoriaux.
*   **Offres** : Catalogue des offres d'emploi, de stage et d'alternance.
*   **Formations** : Liste des parcours (Bureautique, Insertion, etc.) et liens d'inscription.
*   **Contact** : Formulaire et coordonnées.

## 🚀 Installation et Lancement

Puisqu'il s'agit d'un projet Front-End classique, l'installation est très simple :

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/votre-nom-utilisateur/ingeco-territoires.git
   ```
2. Accédez au dossier du projet :
   ```bash
   cd ingeco-territoires
   ```
3. Lancez le projet :
   * Ouvrez simplement le fichier `index.html` dans votre navigateur web.
   * *Ou* utilisez une extension comme **Live Server** sur VS Code pour bénéficier du rechargement à chaud, particulièrement utile pour tester les requêtes `fetch` JavaScript des fichiers locaux.
